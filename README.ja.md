# VPS Checkの使い方

VPSにアプリを公開したあと、サーバーの接続設定を確認したい人向けのツールです。データベースやDockerのポート、SSHの認証設定などを一覧にします。サーバーの設定は変更しません。

VPS Checkの結果だけで、外部から接続できるかや、サーバー全体が安全かは判断できません。

## 配布済みファイルで試す

以下のコマンドは、Windowsではなく、SSHで接続したVPS上で実行してください。実機で確認済みの環境はUbuntu 22.04.5 LTS・x86_64です。

まずCPUの種類を確認します。

```sh
uname -m
```

`x86_64` と表示された場合は、Linux amd64用を使います。新しい作業フォルダにv0.1.0のファイルをダウンロードし、チェックサムを確認します。

```sh
mkdir -p ~/vps-check-v0.1.0
cd ~/vps-check-v0.1.0
curl -fL -o vps-check_linux_amd64 https://github.com/supportapp3-lab/vps-check/releases/download/v0.1.0/vps-check_linux_amd64
curl -fL -o SHA256SUMS https://github.com/supportapp3-lab/vps-check/releases/download/v0.1.0/SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS
```

`vps-check_linux_amd64: OK` を確認してから実行します。

```sh
chmod +x vps-check_linux_amd64
./vps-check_linux_amd64
```

`sudo` を付けなくても実行できます。権限やコマンドが足りずに確認できなかった項目は、`SKIP` と表示します。

`aarch64` と表示された場合の配布ファイルは `vps-check_linux_arm64` です。上のダウンロードURL、保存名、実行ファイル名をすべてその名前に置き換えてください。arm64用はビルドしていますが、実際のVPSでの動作確認はまだ行っていません。

[配布ファイルと変更履歴を見る](https://github.com/supportapp3-lab/vps-check/releases/tag/v0.1.0)

## 結果の読み方

画面の結果は現在、英語で表示します。以下は意味を確認するための日本語の案内です。

| 表示 | 意味 |
| --- | --- |
| PASS | その項目について、想定した設定を確認できた |
| INFO | 状況を説明する情報。必要に応じて確認する |
| WARN | 設定を見直した方がよい可能性がある |
| HIGH | 特に注意して確認したい設定が見つかった |
| SKIP | コマンドや権限などが足りず、確認できなかった |

`PASS` はサーバー全体の安全を保証しません。`SKIP` は問題がないという意味でもありません。

## 何を確認するか

| 項目 | 確認する内容 | 結果を見たあとに確認したいこと |
| --- | --- | --- |
| 接続を待っているポート | サーバー上で接続を受け付けるサービス | 公開する予定のサービスか |
| データベースの接続設定 | よく使うDBのポートが、すべての接続先で待ち受けていないか | DBを外部へ公開する必要があるか、別の制限があるか |
| Dockerのポート | コンテナのポートをどのアドレスに公開しているか | アプリの構成と合う公開先か |
| SSHのパスワード認証 | SSHでパスワードを使う認証が有効か | 接続方法と認証設定が意図どおりか |
| SSHのrootログイン | 管理者アカウントで直接接続できる設定か | 普段の管理方法と合っているか |
| ファイアウォール | UFWの有効状態や、読み取れるnftablesのルール | VPS事業者側の制限も含めて設定を確認する |
| Webサーバー | Nginx・Caddy・Apacheの実行ファイルがあるか | 稼働中か、設定が正しいかは別に確認する |
| 自動更新 | Ubuntuの自動更新用パッケージや設定があるか | 更新の実行結果は別に確認する |

ポートは、通信を受け付ける番号です。SSHは、別のパソコンからサーバーに接続して操作する仕組みです。

たとえば `0.0.0.0` は、すべてのIPv4ネットワークインターフェースで接続を待つ指定です。実際にインターネットから接続できるかは、ファイアウォールやVPS事業者側の設定にもよります。ツールは事業者側の設定を調べません。

## もう少し詳しく見る

通常の表示で省略した情報も確認したい場合は、次のコマンドを使います。

```sh
./vps-check_linux_amd64 --verbose
```

JSON形式で結果を表示したい場合は、次のコマンドを使います。JSONは、他のプログラムからも読み取りやすい形式です。

```sh
./vps-check_linux_amd64 --json
```

結果には接続先のアドレスやサーバーの情報が含まれます。相談するときは、必要な項目だけを取り出し、IPアドレスや秘密の情報を伏せてください。

## 動作の範囲

確認するだけのツールです。設定変更、サービスの再起動、パッケージのインストールは行いません。結果を外部へ送信する機能もありません。

権限が足りないときに自動で管理者権限を取得することはありません。OSや利用できるコマンドによって確認できる項目が変わります。
